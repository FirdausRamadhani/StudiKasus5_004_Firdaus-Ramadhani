## Program Penghitung Biaya Parkir

Program ini adalah sistem sederhana untuk menghitung biaya parkir dan memperlihatkan durasi/lama parkir. 

### Yang ada dalam program ini :

`function` ==> ini adalah fungsi/kode utama dalam program ini. `function` adalah fungsi bawaan python dimana kita bisa membuat fungsi baru atau memberikan tugas khusus kepada kode itu.

`if-else` ==> untuk membuat percabangan pilihan jenis kendaraaan

`print` ==> untuk menampilkan detail khusus seperti lama parkir dan biaya parkir
